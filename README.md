# SPIDER AI — Distribution

Official public distribution repository for SPIDER AI.

This repository is intended for **release assets and public installation metadata only**. The SPIDER AI application source code remains in its private development repository.

## Download

Published, verified releases will appear on the [Releases page](https://github.com/treyoo91z-max/SPIDER-AI-DISTRIBUTION/releases).

Do not download executables from unofficial mirrors.

## Release contents

A release may include:
- A Windows installer (when a Windows build has been validated).
- SHA-256 checksums for every downloadable binary.
- Release notes, supported Windows versions, and known limitations.

## Security and integrity

- Release binaries must be built from an approved source revision.
- Each binary must have a published SHA-256 checksum.
- The installer must verify downloads before execution or installation.
- Never publish API keys, tokens, signing certificates, private source code, user data, or local configuration.
- Never treat an unverified or failed build as a stable release.
