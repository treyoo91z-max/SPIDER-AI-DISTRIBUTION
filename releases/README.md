# Release asset requirements

Place no binary in this folder. Actual installers should be attached to GitHub Releases.

For each release, provide:
1. The installer executable.
2. A `SHA256SUMS.txt` file containing the SHA-256 hash and exact filename.
3. Release notes with version, build/source revision, Windows requirements, and known issues.

Do not publish an installer until it has been built and tested on Windows.
